=================
hostedpi info cpu
=================

.. program:: hostedpi-info-cpu

Get the CPU speed of a Raspberry Pi server

.. code-block:: text

    Usage: hostedpi info cpu [OPTIONS] NAME

Arguments
=========

.. option:: name [str]

    Name of the Raspberry Pi server

Options
=======

.. option:: --help

    Show this message and exit

Usage
=====

Get the CPU speed of a Pi:

.. code-block:: console

    $ hostedpi info cpu mypi
    1.2 GHz
