======================
hostedpi info location
======================

.. program:: hostedpi-info-location

Get the data centre location of a Raspberry Pi server

.. code-block:: text

    Usage: hostedpi info location [OPTIONS] NAME

Arguments
=========

.. option:: name [str]

    Name of the Raspberry Pi server

Options
=======

.. option:: --help

    Show this message and exit

Usage
=====

Get the data centre location of a Pi:

.. code-block:: console

    $ hostedpi info location mypi
    CLL
