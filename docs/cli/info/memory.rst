====================
hostedpi info memory
====================

.. program:: hostedpi-info-memory

Get the memory of a Raspberry Pi server

.. code-block:: text

    Usage: hostedpi info memory [OPTIONS] NAME

Arguments
=========

.. option:: name [str]

    Name of the Raspberry Pi server

Options
=======

.. option:: --help

    Show this message and exit

Usage
=====

Get the memory of a Pi:

.. code-block:: console

    $ hostedpi info memory mypi
    1 GB
