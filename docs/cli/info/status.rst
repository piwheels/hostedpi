====================
hostedpi info status
====================

.. program:: hostedpi-info-status

Get the current status of a Raspberry Pi server

.. code-block:: text

    Usage: hostedpi info status [OPTIONS] NAME

Arguments
=========

.. option:: name [str]

    Name of the Raspberry Pi server

Options
=======

.. option:: --help

    Show this message and exit

Usage
=====

Get the status of a Pi:

.. code-block:: console

    $ hostedpi info status mypi
    Powered on
