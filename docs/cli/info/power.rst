===================
hostedpi info power
===================

.. program:: hostedpi-info-power

Get the power state of a Raspberry Pi server

.. code-block:: text

    Usage: hostedpi info power [OPTIONS] NAME

Arguments
=========

.. option:: name [str]

    Name of the Raspberry Pi server

Options
=======

.. option:: --help

    Show this message and exit

Usage
=====

Get the power state of a Pi:

.. code-block:: console

    $ hostedpi info power mypi
    True
