==================
hostedpi info disk
==================

.. program:: hostedpi-info-disk

Get the disk size of a Raspberry Pi server

.. code-block:: text

    Usage: hostedpi info disk [OPTIONS] NAME

Arguments
=========

.. option:: name [str]

    Name of the Raspberry Pi server

Options
=======

.. option:: --help

    Show this message and exit

Usage
=====

Get the disk size of a Pi:

.. code-block:: console

    $ hostedpi info disk mypi
    100 GB
